#### Introduction to Queue
- Similar ds to stack
- stores data in First In First Out (FIFO)
- Like a line, the first person that got in would be the first to be out
- Used in video games, waiting to play the game
- background processes on the computer e.g downloading or uploading into a cloud
- Printer is implemented with a queue as one page is printed at a time and the next one is placed on the next to be printed
- Can be implemented with an array or with self defined way
